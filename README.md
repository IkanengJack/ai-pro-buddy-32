# AI Productivity Hub

Build a professional, modern, responsive web application called "AI Workplace Productivity Assistant". The application must look like a high-end SaaS platform with a dark/light mode toggle, a persistent sidebar navigation menu, and a clean layout using modern typography and smooth transitions. 

The app must include the following 5 core features, easily accessible via the sidebar:

1. Dashboard Overview: A landing view showing recent activity, a card with a "Responsible AI Disclaimer", and quick-launch shortcuts to the tools.

2. Smart Email Generator: Input fields for "Recipient Context", "Key Points to Include", and a dropdown/button group for Tone Selection (Formal, Friendly, Persuasive, Apologetic). Include a one-click "Copy to Clipboard" button for the generated output.

3. Meeting Notes Summarizer: A large text area for pasting transcripts, with an intuitive "Summarise" action that outputs distinct blocks for "Executive Summary", "Key Decisions", and an interactive "Action Items Checklist".

4. AI Task Planner & Scheduler: A system to input chaotic weekly tasks and output an organized, prioritized schedule sorted by Matrix urgency (Eisenhower method) with editable checkboxes.

5. AI Chatbot Interface: A clean, scrollable chat UI with quick-prompt chips at the bottom (e.g., "Draft a meeting agenda", "Proofread this sentence") and conversational memory bubbles.

UI Requirements:

- A prominent, permanent, professionally styled "Responsible AI Disclaimer" banner in the footer or dashboard home stating that AI data should be verified before professional execution.

- High-fidelity inputs, loading state spinners during "generation" simulations, and clean text containers with "Edit Output" text areas so users can manually refine results.

- Sidebar must collapse gracefully on mobile devices into a hamburger menu.
